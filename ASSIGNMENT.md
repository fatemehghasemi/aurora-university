# AuroraUniversity Project Assignment

## Objective
The purpose of this project is to build a University Management System with a clean, multi-layer architecture. The system should allow managing students, courses, and enrollments, following Domain-Driven Design and Test-Driven Development practices.

## Requirements
- Multi-layer solution: Domain, Application, API
- RESTful API endpoints for enrollment and student management
- Unit and integration testing
- Clean Architecture and Repository-Service Pattern
- Dockerized API for easy deployment

## Deliverables
1. Full solution with projects:
   - `AuroraUniversity.Domain`
   - `AuroraUniversity.Application`
   - `AuroraUniversity.API`
   - `Tests` (Unit and Integration)
2. README.md with instructions for local run and Docker
3. LICENSE file (MIT)
4. Dockerfile for API
5. Gitignore file
6. Optional: Docker Compose setup

## Notes
- Use in-memory database for local development and testing.
- Follow clean code principles.
- Document all API endpoints in README.md.
